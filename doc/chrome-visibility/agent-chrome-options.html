  • Without any subcommand: the hook still records every open, navigation and close by itself. The command only adds what the hook can't guess, and the authorization.
  • Which subagent: in subagents mode the hook adds --agent-id <id> to each command a subagent runs (its shell cannot see its id); agents never type it. Jobs set CHROME_MODE (default single).
  • Which session: always the one running the command, read from $CLAUDE_CODE_SESSION_ID (Claude Code sets it in every agent shell; the hook gets the same id). Outside Claude Code the 4 session commands refuse to run; status and open-profile-window work anywhere.
  • A scheduled job without a shell sets CHROME_PURPOSE, CHROME_VISIBILITY and CHROME_VISIBILITY_REASON in its environment instead of running authorize-tab.
  • Scripts (headless) don't use this command: they call headless(data_dir, purpose, url, keep, needs_human, flags); data_dir and purpose required.
  • Old names chrome-claim and chrome-who keep working until 8 Nov 2026.
